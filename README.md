# 📚 Library Management System

A simple C++ console-based Library Management System that allows users to add, display, search, borrow, and return books. Ideal for beginners looking to strengthen their Object-Oriented Programming (OOP) concepts.

## 🚀 Features

- 📖 Add new books
- 📚 Display all books
- 🔍 Search book by ID
- ✅ Borrow a book (updates status)
- 🔁 Return a book (updates status)

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- Console Input/Output

## 🧪 How to Run

You can compile and run this project using any C++ compiler. For example, using **g++**:

```bash
g++ LibraryManagementSystem.cpp -o library
./library
